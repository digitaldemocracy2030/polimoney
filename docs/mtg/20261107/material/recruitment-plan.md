# X / note 広報メンバー募集 — 作戦と文面

## 募集する役割

| 役割 | 内容 | 求める姿勢 |
|---|---|---|
| **📣 広報・コンテンツ企画メンバー** | noteやXで何をどう発信すべきかを **一緒に考え**、記事や投稿を作る | 政治的中立を守りつつ、わかりやすく伝えることに興味がある |

> 「指示されたものを書く」ではなく、**「何を発信すべきかを一緒に考えるところから」** 参加してほしい

---

## 大前提: Polimoney の立ち位置

> [!IMPORTANT]
> - Polimoney は **政治的に中立** なプロジェクト
> - 特定の政治家・政党を批判も支持もしない
> - 事実データを **そのまま見える化** することが目的
> - 「良い/悪い」の判断は市民に委ねる

この原則は全てのコンテンツに適用される。募集文面にもこの姿勢を明記する。

## 作戦

### なぜ Slack コミュニティから募集するか

- dd2030 の Slack には **シビックテックに関心がある人** が既にいる
- 「透明性」「オープンデータ」に共感するモチベーションの高い層
- エンジニア以外の貢献を求めている人も多い（コードを書けないけど何かしたい層）

### 募集のポイント

1. **「企画から一緒に考える」を強調**
   - 単なる執筆作業ではなく、コンテンツ戦略の立案から参加
   - 「何を書くか」も含めて一緒に決める

2. **政治的中立であることを明記**
   - 批判でも応援でもなく、「事実の見える化」
   - 安心して参加できる環境

3. **ハードルを下げる**
   - まずはミーティング1回参加からでOK
   - 継続義務なし

4. **統一地方選という時間軸を共有**
   - 2027年4月に向けて一緒に準備する仲間感

## 投稿後のフォロー

### 反応があった場合

1. **DM で軽くお話し**
   - Polimoney の概要を共有（README のリンク）
   - 相手の興味・得意なことを聞く
   - 「まずは次のミーティングに参加してみませんか」

2. **キックオフミーティング**（30分〜1時間）
   - Polimoney の現状とビジョンを共有
   - 「政治的中立」の原則を共有
   - **一緒にコンテンツ戦略を考える**:
     - 誰に届けたいか（ターゲット）
     - どんな切り口なら中立を保ちつつ興味を引けるか
     - noteとXの役割分担
     - 選挙前のスケジュール感

3. **継続の仕組み**
   - Slack に `#polimoney-広報` チャンネルを作る
   - 隔週で30分のオンライン定例（企画会議）
   - 記事の下書き共有（Google Docs等）

### 反応がなかった場合

- 1週間後にリマインド投稿（切り口を変えて）
- 他の dd2030 プロジェクトのメンバーに直接声をかける
- Code for Japan 等の外部コミュニティにも展開を検討
