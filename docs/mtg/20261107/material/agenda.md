## 4. 【議論①】 政務活動費（F-11b）をスコープに含めるか（10分）

### そもそも政務活動費とは？

- **地方議員に支給される公金**（月額数万〜数十万円）
- 使途: 調査研究、資料購入、広報、人件費など
- **根拠法が政治資金とは別**（地方自治法 + 各自治体条例）
- 不正使用（領収書改ざん、私的流用）がしばしばニュースに

### 3種類の「収支報告書」の違い

| | 政治資金収支報告書 | 選挙運動費用収支報告書 | 政務活動費収支報告書 |
|---|---|---|---|
| **根拠法** | 政治資金規正法 | 公職選挙法 | 地方自治法 + 条例 |
| **対象** | 政治団体 | 選挙候補者 | 地方議員・会派 |
| **お金の出所** | 献金・パーティー等 | 選挙運動費 | **税金（公金）** |
| **提出先** | 総務省 or 都道府県選管 | 選管 | 議会事務局 |

### なぜスコープに含めるべきか

- 地方議員にとって「お金」は政治資金・選挙資金・政務活動費の **3つの財布** がある
- 混同がミスや不正の温床になっている（問題 B-2）
- Ledger で3つを分離管理できれば、**地方議員にとっての価値が格段に上がる**
- 既存の「セムカン」は政務活動費専用だが、政治資金は対象外 → 棲み分け可能

### 決めること

- [ ] 政務活動費を Polimoney のスコープに含めるか？
- [ ] 含める場合、Ledger の機能として実装するか、別プロダクトか？
- [ ] 優先度は？（まずは政治資金に集中し、後から追加？）
