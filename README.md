# Polimoney

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/digitaldemocracy2030/polimoney)

Polimoney は[デジタル民主主義2030](https://dd2030.org/)のオープンソースプロジェクトです。政治資金のデータを集めて見やすく表示し、市民が政治とお金の問題に自分で気づけるようにします。

## 目的

> 政治とお金に関する問題を実感したり発見できる場をつくり、政治とお金への関心を高める。

Polimoney は問題そのものを解決したり、政治家を評価したりはしません。データを見られるようにするまでが役割で、判断は市民に委ねます。

## 市民に気づいてほしい問題

政治とお金には、次のような問題があります。どれも、市民が自分で見て考えてほしいものです。

| #   | 問題                               | 説明                                                                                         |
| --- | ---------------------------------- | -------------------------------------------------------------------------------------------- |
| P-1 | 企業・団体献金の不透明さ           | 誰が、なぜ、いくら出しているのか、見返りはあるのかが市民から見えない                         |
| P-2 | 政治資金パーティーの実態がつかめない | パーティー券を誰が買ったかが、限られた範囲でしか公開されない                                 |
| P-3 | 政策活動費                         | 2025 年以前は、政党から政治家への支出の使い道が公開されなかった。2026 年 1 月に廃止されたが、過去の分は今も追えない |
| P-4 | 第三者による監視がない             | 選挙管理委員会は書式を確認するだけで、中身を監査する仕組みがない                             |
| P-5 | 個人献金が少ない                   | 政治資金が企業・団体からの献金に偏っている                                                   |
| P-6 | 3 つの財布の混同                   | 政務活動費・政治資金・個人のお金の区別があいまいで、ミスや不正が起きやすい                   |
| P-7 | 記載ミスが起きやすい               | 単式簿記が前提で、少人数で運営され、制度も複雑なので、悪意がなくても正しく報告しにくい       |
| P-8 | 地方の政治資金が見えない           | 議員の 9 割以上を占める地方議員（約 31,500 人）の政治資金が、市民からほとんど見えない         |

## 気づくのを妨げている 4 つの壁

市民がこれらの問題に気づけないのは、間に 4 つの壁があるからです。Polimoney が取り組むのは、この壁を取り除くことです。

### データアクセスの壁：データにたどり着けない

| 障害                                   | 国政                | 地方             |
| -------------------------------------- | ------------------- | ---------------- |
| 収支報告書が PDF で、検索・集計できない | 2027 年にデータベース化 | 変わらない       |
| データが総務省と 47 都道府県に散らばっている | 集約される          | ばらばらのまま   |
| 都道府県ごとに PDF の様式・公開方法が違う | —                   | 統一された様式がない |
| 公開まで 1 年以上かかることがある       | 多少よくなる        | 変わらない       |
| 一定期間がたつと見られなくなる         | よくなる見込み      | 保存されない     |
| 政治家と、その政治家の政治団体が結び付けられていない | 未解決              | さらに深刻       |

国政は 2027 年からのデータベース化でかなりよくなりますが、地方はこのまま残ります。

### 理解の壁：データがあっても読み解けない

- 「組織活動費」「宣伝事業費」などの用語が一般の人には分からない
- 数字が並んでいても、何が問題なのか分からない
- 支出が多いのか少ないのか、比べる基準がない
- 政治資金・選挙運動費用・政務活動費の 3 種類の報告書は、根拠となる法律も対象者も違うのに区別されていない

### 関心の壁：そもそも見ようとしない

- 政治資金の問題を自分のこととして感じられない
- 疑問を持っても、共有したり声を届けたりする場がない

### データ供給の壁：使えるデータが入ってこない

- 報告書の作成は手作業・紙が中心で、地方議員には人手が足りない
- 地方議員の提出は紙が主流で、オンライン提出は任意のため進まない
- 自分から情報を公開したい政治家にも、そのための手段がない

## 3 つのプロダクトと広報

| 取り除く壁       | 担当                                                                     | やること                                                     |
| ---------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------ |
| 理解の壁         | **Polimoney（Web）**（このリポジトリ）                                   | データを見やすく表示し、市民が問題を実感・発見できる場をつくる |
| データアクセスの壁 | **[Polimoney Hub](https://github.com/digitaldemocracy2030/polimoney_hub)**（データ基盤） | 全国の政治資金データを集めて構造化し、検索・比較できるようにする |
| データ供給の壁   | **[Polimoney Ledger](https://github.com/digitaldemocracy2030/polimoney_ledger)**（会計ソフト） | 地方議員の会計の手間を減らし、入力した時点でデータを構造化する |
| 関心の壁         | **広報・アウトリーチ**                                                   | 市民に政治とお金への関心を持ってもらう                       |

### Polimoney（Web）

- 選挙区検索（郵便番号から、国会議員・県議会議員・市議会議員の一覧を出す）
- 収支のまとめ（円グラフ・サンキー図）
- 用語のやさしい説明（ツールチップ）
- 議員 2 人を並べて比較
- 収支の特徴を文章で説明する自動要約
- SNS でシェアするための画像（OGP 画像）の自動生成
- 透明度スコア（公開している項目の数や更新の頻度から計算）
- 公認バッジ（Ledger から公開されたデータであることを示す）

### Hub（データ基盤）

- 47 都道府県の選挙管理委員会の PDF を集めて構造化する
- 国政のデータベースとの連携（2027 年からの総務省の API を使う）
- 全国を横断して検索できる共通のデータ構造
- 政治家と政治団体の名寄せ（政治家 ID）
- 過去データの保存
- データのダウンロード（CSV / JSON）と公開 API

### Ledger（会計ソフト）

- 日々の記帳から法定の報告書を自動で作る
- 政務活動費と政治資金を分けて管理する
- Ledger のデータを Hub 経由で Polimoney に公開する

手書きの PDF を読み取るのは難しいですが、Ledger を使う人が増えれば、入力した時点でデータが構造化されるので、PDF を読み取る必要そのものが減っていきます。Ledger と Hub はこの点で補い合います。

### 広報・アウトリーチ

- note 記事（政治資金の仕組みの解説、データ分析など）
- X への投稿（データの見どころ、選挙までのカウントダウンなど）
- 選挙前の候補者の資金比較記事
- 開発の記録の発信（コントリビューターの募集）
- 政治家への Ledger の紹介・研修
- メディア・研究者への紹介

## 技術情報

### Getting Started

```bash
npm install --legacy-peer-deps
npm run dev
```

### プロジェクト構成

```text
polimoney/
├── app/                  # Next.js App Router のページ
├── components/           # React コンポーネント
├── data/                 # 政治家・政治資金・選挙収支のデータ
├── models/               # TypeScript 型定義
├── public/               # 静的アセット
├── utils/                # データ変換・集計ユーティリティ
├── docs/                 # ドキュメント
├── next.config.ts        # Next.js 設定
├── biome.json            # Biome 設定
└── package.json          # npm scripts / 依存関係
```

### 主なページ

- `/` - トップページ
- `/politicians` - 政治家一覧
- `/politicians/[politicianId]` - 政治家詳細
- `/politicians/[politicianId]/political/[dataId]` - 政治資金収支報告
- `/politicians/[politicianId]/election/[dataId]` - 選挙運動費用収支報告

### データの追加・更新

政治家一覧に表示する情報は `data/politician-master.ts` で管理しています。

政治資金収支報告のデータは `data/demo-*.ts` と `data/politician-data.ts` に定義されています。選挙運動費用収支報告のデータは `data/election-finance/ef-*.json` に配置します。
